## v2.0.76 — 插件商城适配：与壁纸引擎 / 右侧栏插件共存

这版把「三个插件同装时谁画背景」定成契约，README 新增 **插件商城适配** 一节（含适配清单表）。

### ③ 自选背景：现在**我们完全不画**

| 状态 | 背景由谁画 |
|---|---|
| ③ + `dsh-plugin-wallpaper-engine` 正在渲染 | **它**（我们的流体卸载、主题底色让位、连纯白也不画） |
| ③ + 没有壁纸引擎 | **我们**：纯白（浅色）/ 纯黑（深色） |
| ③ + 填了图片 / CSS 值 / 点「桌面壁纸」 | **我们**（壁纸引擎在跑时，它在它的图层之下） |
| ①②/浓三色 | 我们（和以前一样：per-colour 渐变 + 流体） |

- **怎么知道壁纸引擎在画？** 只读它自己的标记：`body[data-we-wallpaper]`（渲染时置上、停止时移除），本插件用 MutationObserver 跟随，**不读它的设置、不写它任何属性、不碰它的 DOM**。
- **为什么"不画"才对**：它的壁纸层是 `.we-layer{position:fixed;inset:0;z-index:-2}`——在 body 背景**之上**、内容之下。我们在 body 上画什么都看不见，拿白色去垫只会制造一层多余的东西。
- **让位是选择器让位**：主题自己的四条背景规则带 `:not([data-dshome-bg=custom])`，进 ③ 直接不匹配，所以壁纸引擎自己的 `body[data-we-wallpaper]` 样式不会被我们压掉（不搞 `!important` 对打）。
- **颜色只驱动按钮**：蓝/绿/红只改品牌 token、按钮、玻璃边色之类，不参与背景。

### `desktop` 改成显式取值

留空**不再**等于"用本机壁纸"（那是 2.0.75 的临时语义，已改）：

- **留空** = 不画（纯白/纯黑，或让位给壁纸引擎）；
- **点「桌面壁纸」按钮**（写入 `desktop`）= 用本机壁纸，宿主端读取路径与铺满方式不变（`TranscodedWallpaper` → 注册表 → 纯色；`WallpaperStyle` → `cover/contain/100%/auto`）。

### better-sidebar（右侧栏）：不越界

- 只把 `[data-dsh-better-sidebar]` / `[data-dsh-center-col]` 当**只读线索**（文档与自查），不写中心列尺寸、不动它的 tab 栏与面板内部；深色规则只覆盖产品原生右栏表面。
- **已知交互写进 README**：它的面板宿主几何同步遇到**页面级 transform** 会降级（它自己会打 `data-dsh-panel-host-degraded`）。本主题的「对话框悬停倾斜」写的是**卡片级** `transform`，正常无碍；若同装后出现悬停抖动 / 底部滑块闪动，按 README 的两步二分：先关 **动态背景**，再切 **白磨砂**（白磨砂下倾斜不生效）。
