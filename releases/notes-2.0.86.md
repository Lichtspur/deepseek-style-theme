## v2.0.86 — 大方块根因 / 玻璃恢复模糊 / 倾斜加强

三条一起发，都来自你这两轮反馈。

### 1. 流体「大方块」——根因找到并修在源头

调查（分层截图 + 参数消融）证明方块在**流体画布自己的像素里**，且**与精度无关**：那台机器 `rgba16f`、`highp` 都已生效，方块依旧 —— 所以 2.0.74（精度）与 2.0.81（存储格式）都不是这个部位。

真因是 `DISPLAY_SHADER` 里那个经典哈希 `fract(sin(dot(st, vec2(12.9898,78.233))) * 43758.5453123)`：这个着色器把噪声坐标放大到 ~2900（`uv *= ns * u_resolution`，`n2` 再乘 2），`dot()` 于是到 ~2e5；float32 在 `sin()` 参数规约后残留的 ~2.5e-3 误差被 43758 放大成 ~100 个单位 → **哈希不再随机**，相邻格子取到几乎同值 → 域扭曲场塌成"大片纯色平台 + 陡边界"（那台机器实测：平坦 8×8 块占 **39.6%**、最大平台 **800×1000px**、边界跳变 **60–90/255**），时间项让平台缓慢平移 = 你看到的"大方块向左下漂"。

**改法**：`random()` 换成 **Dave Hoskins 的无 sin 哈希**（`fract(vec3(p.xyx) * 0.1031)` + 一次 dot + 一次乘加）。所有中间量都很小、跨 GPU 一致，并且**保留上游的逐像素噪声**——不是靠删掉域扭曲治症状（消融里 `noDistort` 确实有效，但那等于把效果删了）。这是对上游 shader 的第 2 处记录在案的改动，与第 1 处同源：一处是 16 位中间精度塌陷，一处是 32 位参数幅值塌陷。

**复测**：用你那套脚本重跑，平坦块占比应从 ~40% 掉到 **20% 以下**；`jumpMax` 期望落到 11–13 区间（消融里的下限是 11.40）。

### 2. 玻璃「凝胶／没有背景模糊」——折射滤镜，默认关

`backdrop-filter: url(#…) blur(8px) saturate(1.75)` 里，**SVG 滤镜一旦渲染失败，整条声明都会失效**：面板于是既没有折射、也没有模糊，只剩半透明填充；滤镜内部的染色（作用在 `|背景 − 背景左移14px|` 上，而渐变背景让这个差值整块面板都非零）再叠上去，就成了"凝胶"。这个功能自 1.43.6 起从未挂上过，默认打开等于拿玻璃冒险：

- **折射改为 opt-in**：`composerRefraction` 默认 `off`，而且 `off` = **整条滤镜链不进 DOM**，四个面都保留 `blur + saturate`（开关一次管全部，不是只管对话框）；
- `TINT_OPACITY` **0.45 → 0.16**（打开折射时，染色只是提示，不再是一层洗色）；
- 新增 **`__dshomeDispersion()`** → `{ composer, mounted, filters, recipe }`。

> 想立刻恢复：DSTT 设置 → 折射 → **关**（2.0.86 起这也是默认）。

### 3. 倾斜加强

`TILT_MAX` 0.0175 → **0.03**、`TILT_SCALE` 1.01 → **1.015**（"倾斜效果很微弱"）。因为 2.0.85 的触发是几何判定，加强后必须防"卡片自己动出指针 → 释放 → 再进 → 再倾"的帧级回路，所以加了 **`TILT_RELEASE_PAD = 8`**：指针要离开卡片矩形 8px 才释放（抬升能移动的边缘不到 2px，余量充足）。

### 装完请验三行

```js
window.__dshomeBuild          // 期望 '2.0.86 glass-on noise-fix'
__dshomeDispersion()          // 期望 { composer: 'off', mounted: false, filters: 0, ... }
__dshomeTilt()                // 鼠标放到对话框上：engagements 增长、leaning: true、spots: 1
```

背景配方若不是「关闭流体」，大方块那条请用你的脚本复测平坦块占比。
