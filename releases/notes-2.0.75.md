## v2.0.75 — 动态背景总开关 + ③ 留空用桌面壁纸

两件事，都在这版。

### 1) 动态背景：开关（默认开）

不再跟集显硬碰。设置页 **DSTT → 动态背景（流体）**，关掉后：

- **不挂载 WebGL2 流体，也不回落到粒子** —— 不是把它藏起来（藏起来的画布照样在算，正是集显最受不了的），而是**根本不创建**。GPU 占用归零，背景只剩静态配色。
- ①②/浓三色下就是那套 CSS 底色；③ 下就是你自己的图或纯色。
- 2.0.74 的 `mediump → highp` 修复仍然保留：`highp` 负责"算对"，这个开关负责"不想让它算"。若那台机器装了 2.0.74 仍是方块，说明主因是第二条（8 位、1/4 分辨率流场的量化），开关能立刻绕过；有空我再按 1/2 分辨率或 `RGBA16F` 去修本体。

### 2) ③ 自选背景：输入框留空 = 用你的桌面壁纸

- **网页读不到系统壁纸**（没有这种 Web API），所以这一步交给**宿主端**：优先读 Windows 的 `TranscodedWallpaper`（当前真正显示的那张，含每屏裁切、幻灯片当前帧、纯色），退回注册表里的壁纸路径，再退回注册表的纯色值。
- 图片走**同源围栏下的 GET 子路径**发给本页当 CSS 背景。该端点**不收任何输入**（没有路径参数、没有查询串），所以它能供出的永远只有宿主自己解析到的那张图。
- **铺满方式跟随 Windows 的 `WallpaperStyle`**：10 填充 / 22 跨屏 → `cover`，6 适应 → `contain`，2 拉伸 → `100% 100%`，0 居中 → `auto`；`TileWallpaper=1` 则平铺。页面上和桌面看起来一致。
- 输入框右边实时显示状态（已就绪 / 纯色 / 读取中 / 读不到 → 用主题底色），旁边有「**桌面壁纸**」按钮一键切回留空。留空或读不到都不会白屏：退回主题底色。
- **隐私**：只在你选了 ③ 且留空时读一次本机壁纸，只发给本页（回环），**不上传、不缓存、不落盘**。会话记录里不会出现壁纸内容。

### 本机实测（宿主端端点）

```
status : {"kind":"image","url":"/dshome-open-workspace/wallpaper","source":"transcoded","style":22,"tile":false}
bytes  : 200 image/jpeg 452964 B (JPEG magic ok)
```

另外沙箱下 `spawn EPERM`（Node 抓子进程输出被拦）会被端点吞成 `ok:false`，客户端随即退回主题底色 —— **失败路径也验过**，不会卡在半截。

### 怎么用

装好后：设置 → DSTT → **动态背景** 关掉（那台集显）；同一页把 **背景方式** 选 ③，输入框留空即用桌面壁纸，想手动指定就填图片 URL 或任意 CSS 值。控制台可确认版本：`window.__dshomeBuild` → `2.0.75 wallpaper+ambient-switch`。
