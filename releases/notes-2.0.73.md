## v2.0.73 — 背景方式四选（① 主色+纯白+近白 / ② 主色+纯白 / ③ 自选背景 / 浓三色）

你要的三档 + 保留的浓三色，做完了。面板里是 DSTT 选项卡下新的一行「背景方式」，**切换即时生效，不用刷新**。

### 四个档位

| 档位 | 面板 | 流体三色（浅色，蓝族为例） | 参与颜色 |
|---|---|---|---|
| `classic` **默认** | ① 主色+纯白+近白 | `#5E82DE #FFFFFF #D8E2FA` | 3（同色系，没有第二种色相） |
| `white` | ② 主色+纯白 | `#5E82DE #FFFFFF #FFFFFF` | **2**（第三个 uniform 复用白，深色复用该族近黑） |
| `custom` | ③ 自选背景 | 无流体画布 | 0 |
| `bold` | 浓三色 | `#1E6FE8 #7FA8F5 #2B57C9` | 3 |

**① 是默认**：你翻出来的那两张截图（红一套、蓝一套，按钮和背景同色系）就是这套，调色板是从 `v1.43.11` 逐字节抄回来的，所以观感就是那个。绿、红、蓝三族的浅色三元组里都带纯白 + 一个近白，深色是「主色 + 近黑 + 深同族」，规则没动。

**② 主色+纯白**：同一软主色，只留纯白。着色器还是三个 uniform，所以第三个复用白色——真正参与的只有两个颜色，白占三分之二，是四档里最干净的一档。深色下白换该族的近黑（`黑蓝` 是蓝黑、`黑红` 是红黑，不是共用一个灰）。

**③ 自选背景**：
- 输入框收**图片 URL 或任意 CSS 背景值**：`https://…/bg.jpg`、`linear-gradient(...)`、`#1F6B4E` 都行。合法性交给浏览器（`CSS.supports`）判定，输入框右边实时显示「可用 · 图片 / 可用 · 纯色 / 暂不可用 / 留空 = 用回默认底色」。
- **颜色只驱动按钮**（品牌 token 照旧跟随绿/蓝/红，玻璃、选中态、按钮全都还在），背景完全是你给的那个。
- **流体画布整体卸载**：不是藏起来——0.55 的流体洗色盖在图上会把它糊掉并重新染色，所以这一档下背景层直接不挂载；切回 ①②/浓三色会自动挂回来。
- **深色模式加 55% 深色蒙版**：蒙版是 `background-image` 的第一层（`linear-gradient(rgb(0 0 0/.55),…)`），图在下面仍然看得见，纯色背景同样压这一层，深色下文字不会糊在亮图上看不清。
- **写错不白屏**：值不合法或为空时那几条 CSS 根本不匹配（靠 `data-dshome-customkind` 门控），页面退回主题自己的底色，而不是给一张白纸。

### 怎么调 / 怎么回退
- 想更淡：`style.opacity`（画布现 0.55 → 0.4）。想更浓：换 `bold` 档，或改三色三元组的第一个值。
- 一档一档点着看就行，四个档都不需要刷新；设置写在 `settings.yaml` 的 `deepseek-style-theme` 段（`backgroundMode`、`customBackground`）。

### 发布前复核修掉的三处（其中一个是从 1.43.6 就埋着的老雷）

独立复核（只读、钉在提交上）抓出两处 blocker + 一处 should-fix，都已修：

1. **`darkSync` 不在作用域里**：`startAmbient()` / `startParticles()` 读它，而它是 `apply()` 的局部变量 → 每次挂载抛 `ReferenceError`，被挂载处的 `try/catch` 吞掉，**画布起来了却没有 disposer**。这正是「③ 卸载画布」失效的原因（流体照旧盖在你的图上），也让无 WebGL2 的粒子回落「append 了但不 resize、不动画」。已提到工厂作用域。**副作用（好的那种）**：深浅色切换订阅、令牌 MutationObserver 现在真的注册了；无 WebGL2 的机器上粒子回落从「死背景」变回可用。
2. **③ 的「纯色」没画上去**：样式表第一行 `html,body{background-color:transparent!important}` 压过非 `!important`，所以纯色静默失效（同时主题渐变已被基规则清掉）。三条 `background-color` 已加 `!important`。
3. **裸 URL 被面板自己拒了**：占位符第一个例子是裸 URL，但它不是合法 CSS 记号 → 已新增归一化，URL 形状的值自动包成 `url("…")`。

另外：未提交的草稿在面板卸载前会先提交（Esc/关设置不再丢）、启动不再闪一下流体（等首次读取落地再挂）、`data-dshome-bg` 的注释修正为 `<body>`。
