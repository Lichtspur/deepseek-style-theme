## v1.43.8 — 流体配色改用上游的 HSL 公式（背景终于能一眼看出颜色）

用户反馈「切主题模式背景不变」的**真正原因在这一版才修掉**：不是没换色，是颜色淡到读不出来。

实测（无头浏览器截图 + 取像素，同一页面、同一 `data-dshome-color=green`）：

| | 像素 | 读数 |
|---|---|---|
| 画布可见 | `235,240,252` | 蓝通道最高 → 蓝白 |
| 画布隐藏 | `233,242,241` | 绿通道最高 → 白绿 |

旧调色板的浅色绿是 `#4FBE92 / #FFFFFF / #D6F2E4` —— 三个近白色在着色器里做三色柔性混合 + 域扭曲，平均下来就是一层奶白，蓝通道天然最高。所以「按钮变绿、背景没变」的观感完全由此而来；上一版我读的是 `body` 的 computed 渐变（确实立刻变绿），但盖在上面的画布这层没有取像素，判断下早了。

**改法**：`FLUID_COLORS` 那组手挑十六进制换成上游 `dsh-theme-mineradio` 的 `fluidToneColors()` 公式 —— 同一个色相出三个 tone，纯度按上游（`hsl(hue, 1, .27..)` 为lead），白/黑两套走同一条 lightness ramp（`FLUID_DEPTH` = 22 / 26）：

```
绿 白 #00b25f  #c8efdd  #f1f6f4      绿 黑 #097140  #044d2b  #050f0a
蓝 白 #0038b2  #c8d4ef  #f1f2f6      蓝 黑 #092a71  #041b4d  #05080f
红 白 #b2000c  #efc8ca  #f6f1f1      红 黑 #710910  #4d0409  #0f0506
```

色相仍是站点的 152 / 221 / 356（`FLUID_HUES` 不变）。

**想调浓淡**：`FLUID_DEPTH` 一个数字即可 —— 调大变淡（22 → 30 约等于中间的柔和感），调小更浓。
