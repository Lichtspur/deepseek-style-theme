## v1.43.11 — 以 1.43.6 为基线恢复（流体 / 液态玻璃回来了），画布改为柔和叠加

按用户提供的 1.43 副本（`D:\DeepSeek\PluginDeveloping\deepseek-style-theme1.43`，即 v1.43.6 树）恢复 `lib/client.js`：双 id 注册、`PLUGIN_ID` 新名、流体背景、液态玻璃、粒子回落全都在，调色板仍是 1.43.0–1.43.6 那套淡色（**不是** 1.43.8 的饱和 HSL）。

在此基线上只做了两处机械改动：

1. **画布改为叠加而非遮挡**：`style.opacity = '0.55'`。流体画布原本是不透明的全屏色块，压在 `body` 背景（DSTT 颜色令牌真正落地的地方）之上 —— 实测过：令牌为绿时画布读到 `235,240,252`，而它下面的 body 是 `233,242,241`。降透明度让页面背景透出来。
2. **构建标记** `window.__dshomeBuild = '1.43.11 fluid-soft'`：控制台一行即可确认"我装的那份到底跑起来没有"。

**验证**（无头浏览器加载真实页面，插件已装入 profile）：

```

theme canvas     : 1     canvas backend : webgl2 (fluid)     opacity : 0.55
app shell        : true  build marker   : 1.43.11 fluid-soft
loader 注册错误  : NONE
```

**实测背景像素**（同一页面，取画布之上的合成结果）：

| 组合 | 像素 | 观感 |
|---|---|---|
| 白蓝 | 235,239,251 | 奶白偏蓝 |
| 白红 | 240,237,245 | 奶白偏红 |
| 白绿 | 236,240,251 | 奶白偏绿 |
| **黑绿** | 131,150,151 | 灰青（明显变深） |
| **黑红** | 153,133,144 | 灰紫（明显变深） |

浅色三档仍偏奶白 —— 这是流体那三色（主色 + 纯白 + 近白）在着色器里做柔性混合后的平均结果，透明度只能帮到边际。要更明显就得动调色板（把主色换成更饱和的一档），说一声即可。

**回退路径**：`pnpm add dsh-deepseek-style-theme@1.43.10`（= 1.41.2 代码，纯粒子背景）或 `@1.43.8`（饱和 HSL 版）。
